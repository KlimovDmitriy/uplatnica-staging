Payment slips for flat-rate tax and contributions (paušalci)

A flat-rate sole trader pays the tax and three contributions every month, each to its own account. Take the amounts and reference from the Tax Administration decision.

Payment codes (šifre plaćanja)

A payment code has three digits. The first is the payment form, the other two are the basis of payment. Find the right code by number or description.

Model 97: check digit calculator

Enter the reference number without check digits and get the full number ready for the slip. Or verify an existing one.

IPS QR code checker

Load an image of the QR code from a bill or paste the code text. We show what is inside and whether it follows the NBS standard.

Serbian account number checker

Enter an account number and we will check its control digits and bank, so you catch a typo before paying.
